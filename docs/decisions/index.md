# Decisions

One ratified decision per file, numbered once and never renumbered — a
reference to `0026` keeps pointing at the same decision when a neighbour is
inserted. `Status: superseded by NNNN` is how a decision is retired; nothing
is deleted, because the next person needs to know it was once settled.

Unsettled questions are NOT here — they live in `open-questions.md`, because a
question written up as an accepted decision is what the next agent builds on.
